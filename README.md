# 🎯 Caçador de Produtos Shopee

Aplicativo gratuito em Streamlit para a Shopee Affiliate Open API.

## Tem
- Busca por produto
- Mais vendidos
- Maior comissão
- Nota de oportunidade 0–100
- Filtros
- Link de afiliado
- Exportação CSV

## Segurança
Nunca publique sua Secret. Configure `SHOPEE_APP_ID` e `SHOPEE_SECRET` nos Secrets do Streamlit.

## Publicação
Envie estes arquivos ao GitHub e publique gratuitamente no Streamlit Community Cloud.

A API não fornece diretamente a quantidade de afiliados promovendo um produto. A nota desta versão usa vendas, avaliação e comissão.
